## 4. Structural fidelity measurements
Reference-ledger atoms are **chosen source-native before** mapping to roles. Predeclare source-required sets by variant: `N` nodes, `E` directed typed dependency edges, `T` precedence/transition obligations (partial order, phase, guard), `C` restrictions and source negative/null outcomes, `B` boundary/observation placements, `M` nonmergeable source functional distinctions and **all source variants**. Every required set is separately counted; each reference atom must have locatable original source evidence and eligibility status. Reconstructed correspondence is a separately frozen one-to-one or explicitly justified one-to-many **witness relation**, not string label matching. An edge only matches if BOTH endpoints, direction, type, guard and source context match; mere co-occurrence fails. Reconstructed `role` accuracy is evaluated on matchable source-required role-assignment obligations, not on all emitted syntactic roles. `T` correctness checks partial order and typed stateful transition, not just temporal token presence. `C` separately detects omitted negative findings/failed rescues. `B` checks System/W/Gamma/E_exp and `rho/O` direction.

Report per variant every numerator, denominator and missing-source reason for node/edge/role/temporal/restriction/boundary/distinction coverage; paper summary is **micro counts** across *independent declared variants*, with shared/common reference obligations allocated to variant only when actually applicable; show macro mean separately, never assume independence of nested variants. Variant coverage = scored eligible variants / all prospectively declared eligible variants. Report excluded exact-original quantitative targets in a separate original-target ledger: `EXCLUDED_SOURCE_UNRESOLVED`/ `EXCLUDED_PREDECLARED_OUT_OF_SCOPE`, neither numerator nor structural denominator; show count and reason and never label as successful structural match. Source-required structural negative findings DO remain in denominators even if numeric effect size is excluded. Do not double-count numerical claims as structural successes.

Record distinct **syntactic expressibility**, **semantic fidelity**, **mechanistic fidelity** and extra `assumptions` dimensions. An entirely filled v0 role map or a passing source-structural implementation test is **not** a `FULL` verdict. `FULL`: every eligible **critical** source requirement and all eligible noncritical requirements evidenced (coverage all applicable sets 1.0), no source-inconsistent extra assumption, all applicable variants individually FULL, distinct dynamics/context/boundary/limits maintained; evidence anchors and cross-check complete. `PARTIAL`: some positively evidenced faithful content but a source-supported eligible obligation omitted/overgeneralized *without essential contradiction*; exact missing IDs and mechanism consequence disclosed. `FAILED`: documented contradiction or essential source-required mechanism/variant/order/restriction/boundary lost under admissible fair trial with sufficient original source; never reclassify invalid packet or missing source as failure. `INPUT_UNDERSPECIFIED`: crucial primary unavailable, decisive original syntax unreadable, packet omits critical source evidence, or pre-A eligibility invalid; block scientific score. `UNDERDETERMINED`: eligible source exists but original source or legitimate mappings do not determine material model distinction after bounded adjudication; protect disagreement/quantitative unknowns. Hierarchical adjudication: invalid input first; unresolved material meaning before success/failure; explicit contradiction/essential loss then FAILED; any other real gap PARTIAL; only all evidenced FULL. Flag variant-level `NOT_ATTEMPTED` outside five outcome states and paper-level `NOT_ATTEMPTED` ledger, never count missing work as a success.

Denominators published as BOTH (i) planned 40 slots and all predeclared eligible original variant slots, (ii) attempted and evidence-adjudicable variant subsets with all `INPUT_UNDERSPECIFIED`, `UNDERDETERMINED` and `FAILED` separately enumerated. Never estimate target population rates from purposive sample.
