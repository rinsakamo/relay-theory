# Proposed PDF source compatibility v0 — not adopted (QP07)

**Scope boundary:** existing author-approved #399 v2.3.1 accepts complete official-publisher original HTML only. This file proposes an optional **exact-complete-published-PDF primary-source mode** for a *future, separately author-approved protocol version*. No frozen prior source, Grammar v0, historical QP01–07, #398, or MAIN permissions are changed.

**PRE-A source lock for exact published PDF:** DOI, work/version/errata, evidence of published edition and lawful access, PDF bytes length, SHA256, page count, all-page text/visual inventory, original model/variant and lineage manifest, source-critical sections, explicit primary authority and any secondary medium. Do not silently substitute a loosely similar author manuscript. If official original HTML plus original PDF coexist, pick ONE as primary before opening source; the other is cross-check only. Secondary repository HTML (PMC) cannot establish same-publisher HTML/PDF exact-media parity without separate edition/figure/equation evidence. Exclude detached uninspected supplements; in-PDF actual appendices only if prespecified as within the physically received PDF universe.

**PDF evidence locator:** (source_sha256, pdf_page_1_based, printed_page_nullable, in-paper section, concise adjacent anchor, eq/fig/table ID, extraction readability, visual page confirmation, formula glyph confirmation). Render pages before asserting math and figure claims; two-column text extraction is merely a navigation aid, never sole authority for source-critical rendered equations or figure pixels. Unreadable decisive PDF content is an explicit source limitation, not an inferred Grammar residual.

**Fixed logic unchanged:** A full-source decomposition and typed edges, frozen full A and digest; B gets same exact PDF and full frozen A and must check every item/edge plus original source-order omission sweep; C **first** reopens the complete original A before making any patch, then source-local evidence plus all adjacent negative clauses/failures/contradictions, each condition ID resolved to existing A, append-only patch, narrowed claim or unresolved exception, followed by separate full source-order sweep even B=0. Exception-only targeted human approval where necessary, not routine claim-by-claim approval. D/E map into unchanged Grammar v0 and optional **derived** System–World recurrence; distinguish exact original source simulation versus illustrative toy probes and avoid new H2 claims from source-defined CTL.
