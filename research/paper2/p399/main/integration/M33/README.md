## Source 1: Jefferies & Lambon Ralph 2006 — an actual same-battery comparison
DOI 10.1093/brain/awl153, *Brain* 129(8):2132–2147.
Official PubMed abstract and White Rose University repository abstract checked. The source compares semantic dementia (SD) and comprehension-impaired stroke aphasia (SA), finding broadly equivalent semantic impairment scores but distinct cross-task consistency, item familiarity, distractor requirements, semantic error and phonemic-cue profiles. Authors interpret impairment as degraded semantic representations (SD) versus a semantic control problem (SA).

The study itself asks about the **mechanism of semantic impairment**, not an ontological proposition that SA/SD patients instantiate different innate cognitive capacity types. Broadly comparable summaries are not proof of numerical equality or a same-signature equality in the M29 pair law.

## Source 2: Corbett, Jefferies, Ehsan & Lambon Ralph 2009 — independent new observations
DOI 10.1093/brain/awp146, *Brain* 132(9):2593–2608.
Seven SA and eight SD cases were directly compared in a distinct non-verbal object-use battery, finding deficits in both populations with different familiarity and task-control dependence.

These are **newly measured tasks and a different sample**, not a different representation of the original 2006 item response data. This contrast is therefore not evidence that mere quotient-map variation generated all of the empirical discrimination.

## Explicit methods
The paper fixes author-proposed `Q_sem` (whether similar impairment supports same mechanistic semantic capacity type) and a contested `C_sem` (semantic representation degradation vs semantic control dysfunction), while retaining these caveats: the types may instead be a single capacity impaired at different loci; source authors do not commit to our type taxonomy; no calibrated two-system identity likelihood.

- `phi_aggregate(Omega06)`: retrospective coarse summary of the 2006 reported semantic test battery.
- `phi_profile(Omega06)`: retrospective finer item/task-conditional summary of **the same measured 2006 records**. This is an analytical proposal, **not a claimed re-analysis of raw patient records**.
- `Omega09`: 2009 independent group/battery; evidence accumulation, **not** quotient choice.
- Lesion anatomy: different observational modality, **not** a presentation of the exact same behavioral data.

The novel value is a transparent *evidence-attribution routing diagnosis*: generic impairment-level convergence does not automatically justify a claim of mechanistic type sameness. The original researchers already distinguish qualitative mechanisms; the paper reconstructs rather than discovers that scientific contrast. DR is a specific audit procedure already implementable by good existing confirmation methodology.
