## Same-question capacity identity audit: what is constructed and what is original?

Scientific source question (actual): which semantic architecture can explain the observed task generalization and pathology phenotype?

Conditional inference question (constructed): Given two systems with routine semantic competence, is a performance-level structural match good evidence that they instantiate the same MECHANISTIC cross-modal generalization capacity under independently stipulated C?

C distinguishes dependence on a common convergence operation from distributed task-gated pathways. This is NOT a universally justified taxonomy and neither source actually answers the pairwise type-identity question as defined here.

The task map retains ordinary semantic naming and classification competence, losing the stipulated C-relevant causal dependency. Thus a task-success match is underqualified as C-specific identity evidence. A lesion-sensitive map retains cross-modal predicted impairment and anatomical localization. Source-grounded clinical observations constrain mechanisms, demonstrating what extra evidence must be evaluated. The later counterinterpretation shows why even the richer scientific evidence does not uniquely establish the asserted cognitive kind.

**Evidential route:** ordinary predictive/task adequacy -> represented task match (underqualified for mechanistic type identity) -> preservation-provenance audit under fixed Q,C -> lesion-sensitive architectural contrasts with source-based rival -> possible qualified evidential support, subject to mechanistic bridge. A successfully calibrated known map is NOT automatically undercut by a rival.
