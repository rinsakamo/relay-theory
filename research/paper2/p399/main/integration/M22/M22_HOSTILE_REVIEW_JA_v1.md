## Hostile Reviewer 1 — Scientific Representation / Structural Realism

**Recommendation: Reject & Resubmit**

本稿の中心式

> scientific warrant for R ≠ individuative warrant for invariant I exposed by R

は直観的に正しい。しかし、現稿のままではこれが独立した哲学的原理なのか、既存の perspicuity / robustness / epistemic relevance を individuation に適用した帰結なのかがまだ決着していない。

North は、複数の正確な representation の間にも target structure に対する non-pragmatic / objective な perspicuity の差があり得ると論じる。Brousalis は比較に使う similarity/difference が epistemically relevant でなければならないとする。さらに robustness-analysis 文献は、モデル上の結論が assumptions の変更を越えて残ることと、その結論が target について確認的であることを区別してきた（Weisberg 2006; Stegenga & Menon 2017; Lisciandra 2017）。

この背景では、DR は次の一般則の特殊化に見える危険がある。

> model/representation 内の特徴を target についての存在論的証拠に使うなら、その特徴が model choice ではなく target を追跡している根拠を出せ。

これだけなら正しいが新しくない。

より深刻なのは “discriminate” の循環性である。もし discriminate とは「identity inference を正当化するだけの追加証拠があること」を意味するなら、DR は「identity inference は十分な identity evidence を必要とする」と同値になりかねない。

**Reject を回避する最低条件**は一つの反例である。R が独立に、しかも客観的に優れた scientific representation だと認めても、R 内の invariant I に capacity identity の証拠力を与えられないケースを示せ。

最も有望な形は、R が予測目的では superior/perspicuous だが、その成功が二つの mechanistically distinct process を同じ sufficient predictive state に圧縮することで得られるケースである。このとき predictive target に対する R の優位性は認められるが、capacity identity に relevant な mechanistic distinction が捨てられている可能性は残る。

この例が成立すれば、North が representation-level superiority を与えても、DR が invariant-level identity warrant を別途要求する理由が見える。成立しなければ、DR は North の target-sensitive perspicuity に吸収される可能性が高い。

## Hostile Reviewer 2 — Source Provenance / Central Witness

**Recommendation: Reject & Resubmit**

これは現稿に対する最強の Reject 理由である。

著者自身の定義では Representational Defeater を発火させる rival は、単に数学的に定義可能であったり、どこかの科学分野で使われていたりするだけでは足りない。少なくとも independently scientifically motivated であり、relevant source material と compatible であり、identity-relevant verdict を変え、target-relevant evidence によって排除されていない live alternative でなければならない。

M21 は Treur (2007) により大きく改善された。Treur は history-based dependence を present-state mediator を介して factorize する認知モデリング上の独立した先例を与える。したがって CPCG の時間抽象化が「Botvinick–Tulving の overlap を作るためだけに発明された」わけではないことは示せる。

しかし、これは **scientifically motivated** を支える証拠であって、**Botvinick と Tulving のこの二つの source claims に対して source-compatible / live であること**をまだ示していない。

しかも provenance を敵対的に読むと問題はより鋭い。ATT03 の source record は preceding trials の exponentially weighted history を明示的に持つ。一方、中央fine witness の journal-facing説明では Botvinick 側は persistence + time index、Tulving 側は history window + time index とされる。逆に MEM04 の source record の中心は、episodic system の functional distinction、自我、autonoetic awareness、subjective temporal orientation であり、reader-facing text だけでは history-window object がどの source commitment から出たのかを追いにくい。

これは bounded reconstruction が誤っていることの証明ではない。しかし central witness が manuscript 自身の defeater を instantiate するなら、査読者が

> source passage → source-local structured commitment → selected fine bounded object → CPCG が忘れる distinction → coarse object でも保存される source commitment

を二つの source について個別に追える必要がある。

現状の Treur 引用はこの鎖の中央しか埋めていない。

さらに、coarse question の目的を「generic temporally extended state dependence」と置くと、その inquiry target 自体が細粒度の差を irrelevant と仮定していないか、という circularity もある。capacity identity に時間実装が relevant かどうかこそ争点なのに、coarse target の設定だけでそれを忘れてよいことにはならない。

**Reject を回避する最低条件**は、新しい一般文献ではなく source-local audit である。Botvinick と Tulving それぞれについて、何を忘れ、何を保持し、なぜその忘却が当該 source claim と矛盾しないのかを、source locator 付きで示すべきである。

それができない場合、Botvinick–Tulving は “Representational Defeater の実例” から “representation sensitivity の数学的 diagnostic” に格下げすべきである。

## Hostile Reviewer 3 — Cognitive Ontology / General Philosophy of Science

**Recommendation: Reject**

本稿は capacity individuation を扱うように見えるが、直接分析するのは capacities ではなく source-grounded scientific claims である。著者自身、

> claim-level recurrent structure + target alignment + capacity-relevant bridge warrant + representational discrimination → defeasible evidence for capacity identity

と認めている。

この式を受け入れるなら、実証装置の大半は最初の項、すなわち claim-level recurrence とその representation sensitivity を診断しているにすぎない。したがって DR の正確な対象は capacity identity そのものではなく、

> structural evidence を capacity-identity evidence に昇格させる推論

である。

ここを曖昧にしたまま “necessary condition on capacity individuation” と言えば過剰主張になる。mechanistic evidence など別ルートで capacity identity が確立される可能性がある以上、DR は identity simpliciter の必要条件ではない。

もう一つの問題は novelty-to-complexity ratio である。本稿には 60-source corpus、1,770 comparisons、206 bounded objects、99 cross-stratum families、prospective 40-paper analysis、lossless/lossy controls、role grammar、reverse projection、formal audits、model replay がある。しかし著者自身、それらを population evidence、human reliability、empirical validation、positive capacity taxonomy の根拠とはしていない。

すると敵対的編集者はこう問える。

> これらの装置をすべて使わなくても、「representation-dependent recurrence を identity evidence に使うには追加の discrimination が必要だ」という点は一つのよく作られた例で示せるのではないか。

もし答えが Yes なら、本稿は哲学的 payoff に対して方法論的装置が過大である。

1,770/1,770 incomparability も同様である。著者は正しく failed-granularity result と呼ぶが、本文から synthetic reachability control がほぼ消えたため、初見の読者は「comparator が construction 上ほぼ何でも incomparable にするのでは」と疑える。Supplement に control があるだけでは、本文中の最も目を引く数字への疑念を完全には防げない。

**Reject を回避する最低条件**は大規模追加実験ではない。主張を “necessary evidential condition on structurally supported capacity-individuation inferences” に全編統一し、本文を DR → strongest objection → Defeater → central witness → Beni → consequences に近づけ、comparator reachability を2–3文だけ本文へ戻すことで十分である。

独立 human coding は望ましいが、この論文の主張からは publication requirement ではない。むしろ新しい validation lane を開けば、論文の genre problem を悪化させる。

## Hostile Editor Synthesis

**Decision: Reject and Resubmit, with explicit encouragement**

Reject を成立させる最強の論証は「データ不足」ではない。

第一に、central Botvinick–Tulving case が manuscript 自身の **live alternative** 条件をまだ満たしたと示されていない。これは内在的な反論であり最重要である。

第二に、DR が North / Brousalis / robustness の単なる適用を越えることを、現稿は宣言しているがまだ例証し切っていない。representation-level warrant と invariant-level identity warrant が実際に分離する反例が必要である。

第三に、論文の本当の対象は capacity identity ではなく、structural recurrence を identity evidence に昇格させる inferential license である。ここを徹底すれば射程問題はほぼ消える。

したがって次の改稿ゲートは以下で十分であり、新しい60-paper分析やhuman-coding studyは要求しない。

1. **BT source-local provenance / source-compatibility**
2. **North-resistant counterexample**
3. **identity-evidence promotion への全編スコープ統一**
4. **さらに哲学優先に階層化し、reachability controlだけ短く本文へ復帰**

この四つを通過できれば、現在成立する最強の Reject 論証はかなり崩れる。
