# MAIN M24 — Defeater scope and evidential-weight clarification

M24 responds to the post-M23 JGPS-style review without expanding the empirical program.

## Core change

The Discrimination Requirement is now explicitly a constraint on **material individuative evidential weight**, not on evidential relevance simpliciter. A representation-sensitive invariant can remain weak abductive evidence. DR governs whether that invariant is entitled to carry a structurally supported capacity-identity inference.

## Trigger versus defeater

M24 separates two stages:

1. **Representational-Defeater Trigger** — a scientifically motivated, source-compatible unresolved preservation choice changes an overlap verdict that could be recruited for individuation.
2. **Representational Defeater** — if that disputed overlap is actually assigned material individuative weight, the live alternative undercuts that evidential use until the preservation choice is discriminated.

The defeater is undercutting, not rebutting.

## Botvinick--Tulving

The empirical result is unchanged: fine overlap is zero and coarse overlap is positive. Its philosophical role is narrowed. Because no control--memory identity inference is advanced from that overlap, the pair is an **empirical trigger witness**, not itself a fully instantiated defeated identity inference.

## Full defeater illustration

The learning-system example now explicitly contains two warranted representations: a predictive compression and a mechanistic representation preserving distinct update rules. The mechanistic rival undercuts using the shared predictive state by itself to infer same capacity.

## Beni

The manuscript now grants Beni's strongest reply. Natural-kind reasoning supplies empirical criteria and clustered content that can, in principle, discharge DR. DR specifies what those empirical constraints must accomplish when PP--FEP invariants are assigned kind-individuative force.

## Tulving

Past-directed subjective temporal organization is source-grounded. `history_window + time_index` is explicitly marked as the working comparison representation's encoding, not as Tulving's own computational primitive.
