## Why this stage exists

M29 derived the likelihood ratio of two represented matches from one finite pair law, but did not yet distinguish a necessary event-provenance audit from already competent ordinary evidence appraisal. M30 explicitly avoids claiming a novel axiom of confirmation.

### Minimal counterexample

Fix the same pair-generating distribution, same question Q, same provisional capacity criterion C, and a **stipulated** ordinary-task admissibility flag A_T=1 for both report protocols. Under R=x a reported match has LR 4; under R=y it has LR 1. A thin record which contains Q, C, A_T=1, and "match=yes", but discards map identity/event semantics, is identical under both. No function of this thin record can yield the *correct map-specific* LR for both. This is an insufficiency theorem about a particular report projection, not a claim that all standard statistical appraisals make this mistake.

### Adversarial controls

| Report | Qualified inference |
|---|---|
| x map retained and exact event calibrated | LR 4; y rival does not defeat it |
| y map retained and exact event calibrated | LR 1, neutral for H |
| unknown map but independently justified w=1/2 | LR 13/7, not 4 |
| unknown map and unjustified w | a particular LR is not identified |
| bounded event Ex OR Ey explicitly specified | LR 3/2; event not transitive |
| complete generic likelihood + map audit | DR already satisfied; no novel confirmation axiom |
| comparison switches Q or C | not a same-question activated rival |

The **five fields** for assessment are: question and criterion; exact preservation map or selection rule; event semantics; comparison distribution/calibration; and the support actually attributed. An omitted field may be only an incomplete report, not an activated undercutting defeater.

### Scientific and methodological limitations

- Ordinary-task adequacy equality is stipulated for the logical diagnostic; **it was not independently measured** for the two maps in any source.
- The 8-state law and C-classification are schematic rather than independently validated representations of cognitive mechanisms.
- The existence of the rival map alone cannot undercut properly calibrated x-specific support.
- Normal measurement-resolution, aggregation, and identifiability reviews can discharge the full DR; event-construction specificity is the methodological deliverable.
- No real corpus pair is claimed to trigger a same-Q,C identity defeater; independent human reliability remains unmeasured.
