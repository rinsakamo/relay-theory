# MAIN M27 — Representation provenance and matched discrimination

M27 addresses the remaining post-M26 JGPS-style objections without adding a corpus run or changing any scientific headline result.

## Central change

The M26 conceptual example depended on an unperformed intervention and therefore remained vulnerable to the objection that the real problem was ordinary empirical underdetermination.

M27 removes that feature completely.

A fully specified fine space is fixed:

[
\mathcal F=\{a_1,a_2,b_1,b_2\}.
]

An independently declared criterion (C) partitions the space into two capacity types:

[
C(a_1)=C(a_2)=A,qquad C(b_1)=C(b_2)=B.
]

Two representations are stipulated equally adequate for the same ordinary scientific task.

The aligned map has fibers:

[
\{a_1,a_2\},quad \{b_1,b_2\}.
]

The crossing map has fibers:

[
\{a_1,b_1\},quad \{a_2,b_2\}.
]

Nothing is unobserved. There is no unknown parameter and no unperformed intervention. The only difference is whether the preservation map respects or crosses the independently declared capacity partition.

## Normative derivation

M27 explicitly adds a minimal contrastive-support norm:

> If an evidential item is offered as a reason to favor (H) over relevant alternatives, mere compatibility with (H) is insufficient; the item must have some contrastive bearing on (H).

This norm is not claimed as novel.

Structural comparison adds the distinctive fact that the candidate evidential item is generated by a preservation map:

[
phi_R:\mathcal F\to\mathcal S_R.
]

A represented match is:

[
I_R(f_A,f_B)=1
quad\text{iff}\quad
phi_R(f_A)=phi_R(f_B).
]

DR is the methodological corollary: before (I_R) is used as positive identity evidence, the relevant preservation fiber must be shown to discriminate the live (C)-alternatives, or independent evidence must restrict / differentially weight the crossing alternatives.

## Activated defeater

Logical possibility alone is insufficient.

A rival activates undercutting only when it is scientifically motivated, bears on the same (Q,C), exposes a live (C)-relevant distinction, is not already neutralized by background evidence, and changes the stated reason for treating (I_R) as favoring identity.
