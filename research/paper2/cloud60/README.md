1. **Admission and source:** Freeze immutable main40 bibliographic/selection manifest before pilot. Separate pilot identities and model lineages from main. For each input, register DOI/canonical ID, exact edition/correction checks, dated provenance URL, source type, access/equivalence evidence, model variants, readable in-source equations/figures, and source-scope digest before structural work. Where a source is missing/ambiguous, use SOURCE_PENDING / VERSION_UNDERDETERMINED; never infer Grammar failure.
2. **Analysis:** Run each source-bound task in ChatGPT under the appropriate **already-authorized** method. For #399 v2.3.1: full original source → frozen independent A → B sees **exact frozen A + original source**, performs all-A and original-source-order review → frozen B → source-closed C rebuts each B issue and independently repeats source-order sweep. C first compares all immutable original A before proposing any patch and inventories all adjacent in-HTML negative/limiting conditions. Accepted deltas are append-only; unresolved material claims are UNDERDETERMINED; human review is exception-only. Do not backdate development cases.
3. **Freeze:** Store *derived, non-copyright-infringing* stage reports in Git at a distinct commit **after each phase**. Write a provenance receipt listing the exact commit, artifact path and Git-blob byte SHA256 per phase. The receipt is appended **after** the cited freeze commits. Original full PDFs and publisher HTML must remain at lawful access locations outside the public Git repository; record short locators and metadata instead. An Actions artifact is a convenience copy, **not** the authoritative immutable archive.
4. **Reference/blinding for #398:** Keep canonical metadata and independently sourced reference judgments separate from masked reconstruction packets. Preserve variants, model-level topology, leakage/recognition reports, negative controls, comparable denominators and non-unique reconstructions. All MAIN results and the **blind structural atlas must be committed and hashed before labels are restored**. Record actual separation/independence limits; different chats or agents alone do not prove blindness or independent scientific adjudication.
5. **Cloud validation:** Submit GitHub PRs. `.github/workflows/paper2-cloud-first-provenance.yml` runs standard-library Python tests and validates every `research/paper2/cloud60/receipts/*.json` receipt against Git-committed artifacts, hashes and commit ancestry. It rejects a same-commit fake freeze and wrong-track source regimes, but cannot determine whether a quoted source claim is scientifically faithful or find omitted conditions not included in a ledger. Any future P399 v2.3.1 C-validator integration is **additional**, not replaced by this generic provenance gate.
