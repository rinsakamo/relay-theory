# 制限された観測下の操作的個体化
## 表現の複数性と対象の識別可能性

## 要旨

形式モデルの中に複数の表現が存在しても、それだけで複数の個体が存在するとは言えない。

異なる変数、符号化、識別子、あるいは台集合の要素は、表現として異なっていても、同じ対象を指している可能性がある。したがって、表現が複数存在するという事実だけでは、個体が複数存在するという主張は正当化されない。

本論文では、利用可能な観測や介入が制限されている場合に、二つの表現を操作的に別個のものとして扱うために、どのような証拠が必要かを検討する。

形式モデルでは、表現、表現が指す対象、対象を調べるためのテストを明示的に分離する。この分離により、記法や符号化の違いが、対象の違いを示す証拠として暗黙に利用されることを防ぐ。

機械検証された有限モデルから、四つの結果が得られる。

第一に、異なる二つの表現が同じ対象を指し、対象に依存するすべてのテストで同じ結果を返す場合がある。

第二に、あるテスト集合では区別できない二つの表現が、対象に関係する追加テストを導入すると区別可能になる場合がある。

第三に、利用できるテストを増やすことで区別を細かくすることはできるが、テストを追加したこと自体によって既存の区別が失われることはない。

第四に、テスト結果に影響しないメタデータは、対象の区別にも影響しない。

これらの結果から、限定された結論が得られる。

**操作的な区別を主張するには、表現そのものの違いではなく、表現された対象に関係し、かつ認められたテストによって検出される違いが必要である。**

検討した形式的範囲では、表現と対象の対応関係、利用可能なテスト、その結果が固定されれば、操作的な区別を決めるために追加の原始的な同一性パラメータは必要ない。

ただし、本論文は形而上学的な数的同一性を決定するものではない。観測が個体を生み出すとも主張しない。また、有限な観測によってあらゆる可能な差を捉えられるとも主張しない。

本論文の目的はより限定的である。

**表現上の違いと、対象について正当化された違いを分離する。**

## 1. はじめに

二つの表現があるというだけで、二つの個体があると言えるだろうか。

形式モデルでは、二つのものを作ること自体は簡単である。

二つの変数を書ける。

二つの識別子を割り当てられる。

二つの構成子を定義できる。

二つの台集合要素を置くこともできる。

しかし、これらの操作によって直接示されるのは、形式表現が複数存在するということだけである。

**複数の表現は、複数の個体を意味しない。**

同じ対象が異なる名前を持つことはある。同じ状態が異なる方法で符号化されることもある。異なる内部表現が同じ観測結果を生む場合もある。

したがって、表現の違いと、表現された対象の違いを区別しなければならない。

本論文が扱う問いは次のものである。

**どのような証拠があれば、二つの表現を操作的に別個のものとして扱ってよいのか。**

ここで用いる基準は単純である。

**表現の違いは、それだけでは対象の違いの証拠にならない。**

対象の違いを主張するためには、その対象に関係するテストによって実際の差が検出されなければならない。

この基準は、一種の循環論法を防ぐ。

たとえば、形式化の最初に (x) と (y) を別の要素として定義し、後になって (x\neq y) であることを二個体存在の証拠として使うなら、結論が最初から形式表現の中に埋め込まれている可能性がある。

本論文では、この順序を採用しない。

まず複数の表現を置く。

次に、それらが対象に関係するテストによって区別できるかを調べる。

区別できるなら、その観測条件の下では操作的な差が支持される。

区別できないなら、表現が複数あるというだけで個体差を主張することはできない。

本論文の中心原則は、一文で表せる。

**表現が異なるというだけで、表現されたものが異なると推論してはならない。**

## 2. 形式設定

(P) を表現の集合とする。

(P) の要素は、名前、式、符号化、記録、識別子など、対象を形式的に取り扱うためのものとする。

(P) の異なる要素が異なる個体に対応するとは仮定しない。

(T) を対象の集合とし、

[
r:P\rightarrow T
]

を、各表現がどの対象を指すかを指定する写像とする。

(Q) をテストの集合とする。

テストには、観測、測定、問い合わせ、介入などを含めることができる。

対象 (t) にテスト (q) を適用した結果を

[
O(q,t)
]

と書く。

ある分析で利用できるテスト集合を

[
A\subseteq Q
]

とする。

二つの表現 (a,b) が (A) の下で区別できないことを

[
a\equiv_A b
]

と書き、

[
a\equiv_A b
\quad\Longleftrightarrow\quad
\forall q\in A,\;
O(q,r(a))=O(q,r(b))
]

と定義する。

逆に、

[
a\mathrel{\#_A}b
]

を

[
a\mathrel{\#_A}b
\quad\Longleftrightarrow\quad
\exists q\in A:
O(q,r(a))\neq O(q,r(b))
]

と定義する。

重要なのは、この定義の中に

「(a) と (b) はすでに異なる個体である」

という前提が含まれていないことである。

**形式的不等号は、表現が異なることの証拠であって、それだけでは対象が異なることの証拠ではない。**

変数名の違いだけでは足りない。

構成子の違いだけでも足りない。

データ構造内の位置も、隠れた識別子も、それだけでは足りない。

それらが対象の個体化に関係するためには、対象に関係するテスト結果の差として現れる必要がある。

## 3. 表現の違いと対象の違い

二つの異なる表現 (a) と (b) を考える。

符号化そのものを調べる手続きなら、両者を簡単に区別できるかもしれない。

しかし、その結果が示すのは、二つの符号化が異なるということだけである。

参照先が異なることまでは示されない。

形式モデルには、実際にそのような例が含まれている。

二つの表現は形式的には異なる。

しかし、

[
r(a)=r(b)
]

である。

したがって、対象だけに依存するテストは、両者に対して同じ結果を返す。

この例は、

[
a\neq b
]

から

[
r(a)\neq r(b)
]

を推論できないことを直接示している。

**検出可能な差があることと、対象に差があることは同じではない。**

この区別は個体化を議論するときに特に重要である。

モデルの都合で割り当てた識別子を、そのまま二個体存在の証拠として使うことはできない。

それでは、表現を作るための選択が、表現された世界についての結論に変換されてしまう。

正しい順序は、

[
\text{複数の表現}
\rightarrow
\text{対象に関係する差を調べる}
\rightarrow
\text{差が検出された場合に区別を認める}
]

である。

[
\text{複数の表現}
\rightarrow
\text{複数の個体}
]

ではない。

## 4. 区別可能性は利用できるテストに依存する

二つのテスト集合 (A_c) と (A_f) が

[
A_c\subseteq A_f
]

を満たすとする。

(A_f) は、(A_c) に含まれるすべてのテストに加えて、さらに別のテストを含んでいる。

このとき、

[
a\equiv_{A_f}b
\Longrightarrow
a\equiv_{A_c}b
]

が成立する。

より多くのテストを使っても区別できないなら、より少ないテストでも区別できない。

しかし、逆は成立しない。

形式モデルには、

[
a\equiv_{A_c}b
]

でありながら、

[
a\mathrel{\#_{A_f}}b
]

となる例がある。

つまり、少ない証拠では見えなかった差が、追加のテストによって見えるようになる。

この結果は簡潔に表せる。

**より多くの証拠は、より少ない証拠では見えなかった区別を明らかにできる。**

ただし、より豊富なテスト集合が絶対的な同一性を明らかにしたことにはならない。

示されるのは、そのテスト集合の範囲で区別できるということだけである。

有限性についても同様である。

**有限性が個体を作るのではない。有限性は、検出できる差を制限する。**

したがって、本論文で重要なのは、

[
\text{利用可能なテスト}
\rightarrow
\text{検出可能な差}
\rightarrow
\text{支持される区別}
]

という関係である。

## 5. 形式結果

### 5.1 表現が違っても対象は同じでありうる

二つの表現が

[
r(a)=r(b)
]

を満たすなら、対象だけに依存するすべてのテストは同じ結果を返す。

したがって、表現だけを変更しても対象について得られる証拠が変わらない場合がある。

**表現を変えることは、必ずしも対象を変えることではない。**

### 5.2 表現レベルの識別可能性だけでは足りない

形式モデルには、表現上の情報を使えば区別できるが、対象に依存するすべての関連テストでは区別できない二つの符号化が存在する。

したがって、

**ある差を検出できるというだけでは、その差を個体化に利用することはできない。**

検出された差が、個体化の対象そのものに関係している必要がある。

### 5.3 テストを増やすと新しい区別が見つかることがある

制限されたテスト集合では区別できなかった二つの表現が、追加の対象依存テストを導入すると区別可能になる。

したがって、

**区別不能性は、常にどのテストを利用できるかに依存する。**

### 5.4 観測された差から対象の差を導ける

正の例では、対象が異なるということを最初から前提にしない。

対象に依存するテスト結果の差から、参照先の対象状態が異なることを導く。

これにより、結論を前提として使用することを避けることができる。

### 5.5 テストの追加は区別を細かくする

[
A_c\subseteq A_f
]

なら、

[
a\equiv_{A_f}b
\Longrightarrow
a\equiv_{A_c}b.
]

テストを追加すると、それまで同じ分類に入っていたものを分割できることがある。

しかし、追加の証拠そのものが、すでに検出されていた差を消すことはない。

### 5.6 関係のないメタデータは個体化しない

利用可能なテストの結果に影響しないメタデータは、操作的な区別にも影響しない。

**ラベルは、それが証拠として意味を持つときにだけ区別に寄与する。**

## 6. 何を証拠として数えるべきか

検出可能な差がすべて、対象の差を示しているわけではない。

少なくとも二つの問いを分ける必要がある。

第一に、

**その差は、表現についての差なのか、表現された対象についての差なのか。**

第二に、

**その差を検出する方法は、現在の主張に対する証拠として認められているか。**

たとえば、同じ人物を表す二つのデータベース行が異なる行番号を持っているとする。

行番号は二つのレコードを区別する。

しかし、行番号が違うというだけでは、二人の人物が存在するとは言えない。

一般化すると、次の原則になる。

**個体化の証拠は、個体化しようとしている対象の差を追跡しなければならない。**

また、ある形式モデルが認めるすべてのテストを含むテスト集合を考えることもできる。

これは数学的な上限として有用である。

しかし、それは物理的な全知を意味しない。

ここで「最大」とは、その形式モデルの中で許されたテストをすべて含む、という意味にすぎない。

## 7. 既存研究との関係

観測可能な振る舞いによって系を比較する考え方は新しくない。

観測等価性、双模倣、行動等価性などは、指定された観測や相互作用によって二つの系を区別できるかどうかを扱う。

本論文は、それらに代わる新しい等価関係を提案するものではない。

本論文が問うのは別の問題である。

**識別可能性について得られた証拠から、個体化について何を結論してよいのか。**

この問いは、不可識別者同一の原理をめぐる古典的問題とも異なる。

そこでは、完全な性質の一致が数的同一性を含意するかどうかが問題になる。

本論文は、その問題を解こうとしない。

より限定された問いを扱う。

**明示された観測条件の下で、どのような証拠が操作的な区別を支持するのか。**

この限定は、物理学の哲学で論じられてきた「識別可能性」と「数的同一性」の区別とも整合する。

操作的に区別できることは、形而上学的な意味ですべての同一性問題が解決されたことを意味しない。

科学実践における個体化の研究とも近い関係がある。

研究上何を一つの対象として扱うかは、測定方法や研究目的によって変化しうる。

本論文が加える形式的制約は単純である。

**表現装置が生み出した差を、独立した証拠なしに対象の差として扱ってはならない。**

表現の冗長性やゲージ自由度をめぐる議論にも、同じ方法論的注意が見られる。

異なる数学的記述があるからといって、異なる物理状態があるとは限らない。

## 8. 限界

本論文の結果は、一般的な同一性理論ではない。

第一に、

[
\text{操作的に区別できる}
\not\Rightarrow
\text{形而上学的に別個である}.
]

第二に、

[
\text{あるテスト集合で区別できない}
\not\Rightarrow
\text{あらゆるテストで区別できない}.
]

第三に、

[
\text{観測で同じ}
\not\Rightarrow
\text{介入しても同じ}.
]

第四に、

[
\text{有限なアクセス}
\not\Rightarrow
\text{個体性}.
]

第五に、

[
\text{ある時点で区別できる}
\not\Rightarrow
\text{時間を通じて同じ個体を追跡できる}.
]

これらは例外ではなく、本論文の適用範囲そのものである。

現時点で最も強く言える結論は次のものである。

**表現と対象の対応関係、および対象に関係する利用可能なテスト集合が固定されれば、それらのテストが支持する操作的な区別を決めるために、追加の原始的な同一性パラメータを導入する必要はない。**

この結論は、証拠が十分かどうかについてのものである。

形式モデルが、同一性に関係するすべての事実を含んでいると主張するものではない。

## 9. 結論

形式的な複数性は簡単に作ることができる。

二つの名前を書ける。

二つの識別子を作れる。

二つの台集合要素を定義できる。

しかし、それだけでは対象世界に二つの個体が存在することは示されない。

本論文の第一の結論は単純である。

**複数の表現は、複数の個体を意味しない。**

では、何が必要なのか。

第二の結論は次の通りである。

**操作的な区別を主張するには、表現された対象に関係し、明示された観測条件の下で実際に両者を区別する証拠が必要である。**

形式結果は、この二つの原則を具体的に支える。

異なる表現が同じ対象を指す場合がある。

少ないテストでは見えなかった差が、より豊富なテストでは見える場合がある。

テスト結果に影響しないメタデータは、対象の区別を生み出さない。

これらの結果から、さらに一般的な方法論的原則が得られる。

**表現の差を、証拠なしに対象の差へ変換してはならない。**

本論文の主張はそこまでである。

形而上学的同一性一般を解決するものではない。

有限な観測が完全であるとも主張しない。

観測が個体を生み出すとも主張しない。

示すのは、より限定されたことである。

**対象に関係する識別証拠がすでに与えられているなら、その証拠が支持する操作的な区別を決めるために、さらに独立した「個体である」という印を追加する必要はない。**
